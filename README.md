# Sebastian Cervera Maltos Portfolio

Modern portfolio built with Next.js for selected work, applied AI research, Odoo/automation projects, and contact.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deployment

This project is ready for Vercel. Import the GitHub repository and keep the default Next.js build settings.
